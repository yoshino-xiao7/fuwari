## 核心更新

### 1.UI设计

我们抛弃了传统枯燥的后台管理界面，基于 **Naive UI** 打造了一套全新的“极光毛玻璃”设计系统。

- **沉浸式体验**：全站背景采用动态模糊与半透明卡片设计，视觉层次丰富。
    
- **响应式布局**：无论是桌面大屏还是移动端，控制台都能完美适配，随时随地管理你的服务。

### 2. 更加灵活的 API Key 管理

在 v2 版本中，我们引入了更完善的鉴权机制。

- **自主创建**：用户登录控制台后，可自助创建多个 API Key，用于区分不同的项目或环境。
    
- **配额可视化**：在仪表盘中，你可以实时查看每个 Key 的`今日调用`、`总调用`以及`剩余配额`，用量一目了然。
    
- **安全可控**：支持随时重命名、禁用或删除泄露的 Key，保障账户安全。

## 快速上手指南

想要使用 Setu Cloud v2 的服务非常简单，只需三步：

**第一步：注册与登录** 访问 Setu Cloud 官网，使用邮箱注册账号。登录后，你将直接进入全新的用户仪表盘。

**第二步：获取 API Key** 在左侧菜单点击 **「API Key 管理」** -> **「新建 API Key」**。 输入一个备注名称（例如 "My Blog"），点击创建。系统会生成一串密钥，请务必立即复制并保存。

**第三步：发起调用** 现在，你可以使用任何 HTTP 客户端调用接口了。记得在 Header 中带上你的 Key：

Bash

```
## 示例：使用 cURL 调用
curl -X GET "https://api.yukiryou.icu/setu/v2" \
     -H "X-API-Key: sk-你的密钥"
```

## 技术栈一览

对于感兴趣的开发者，Setu Cloud v2 的前端构建于以下现代技术栈之上：

- **核心框架**：Vue 3 (Script Setup)
    
- **构建工具**：Vite 5
    
- **UI 组件库**：Naive UI
    
- **状态管理**：Pinia
    
- **语言**：TypeScript
