## # 前言

ChatGPT 刚把 GPT-6 Astra 丢出来。Claude 那边新模型已经强到有点离谱了，我本来还挺期待：你作为对面那个一直拿编码当门面的，这次总该有点质变吧。

结果不可思议的是——完全没有。

用了几天，编码越来越便秘，Goal 大半时间在审计，前端 UI 还是一坨屎，价格倒是老实涨了。除了把 GPT-5.6 Sol 逼降智之外，我没看出来有什么特别的。

## # 编码：越来越便秘

Astra 宣传上当然还是那套：更强的推理、更稳的长任务、更会写代码。落到实际写代码的手感上，完全不是这么回事。

不是说它完全不会写。是它写得越来越拧：想一步到位的地方要绕三圈，该直接改文件的时候先自我审查半分钟，改完还不一定对。以前 5.6 Sol 至少还能闷头干活，现在连那点利落都没了。

更恶心的是，新模型一上，旧模型也跟着变钝。5.6 Sol 本来还能用，现在感觉像被故意降智了——不是你新模型变强，是把旧的一起往下按，好让人觉得“升级”有意义。

质变？没有。增量？勉强算有。便秘？越来越明显。

## # 审计：用我的 token 做你的安全

Codex 这套安全审计也是逆天。

任务明明已经给了完全访问权限，它还是要停下来打一长串文字，让我再授权一次。不是问一句“能不能改”，是整段整段地复述风险、列文件、等我打字确认。你都拿到全权限了，还在这演安全剧场给谁看？

更离谱的是，这审计烧的是我的 token。

用我的额度，做你的安全流程，还把任务节奏拖成一坨。Goal 挂几个小时，打开一看，大部分时间既不是在写代码，也不是在跑测试，是在审计、复述、等授权。安全是该做，但做成这样就是把用户当免费算力池。

## # UI：能用就行呗？

前端 UI 也是写的一坨屎。真不知道现在的标准是不是“能用就行”。

信息堆在一起，状态看不清，Goal 跑到哪、卡在哪、是在干活还是在审计，界面自己都说不明白。回复还慢。你都把模型价格拉到三倍了，界面还停留在内部工具随便糊一层的程度。

一个 Goal 能跑几小时。大部分时间耗在审计上，界面还不能痛快点告诉我现在到底在干什么。这种产品完成度，配不上这个定价。

## # 价格：1.5 倍还不够，直接 2 倍

以前 Fast 已经是 1.5 倍速消耗了。那点加速换来的东西本来就有限，属于典型的无用消耗。现在直接改成 2 倍速度，更是离谱。

新模型本身也不便宜。按消耗看，GPT-6 Astra 大概是 GPT-5.6 Sol 的三倍；按效果看，最多也就 1.1 倍。三倍价格买一点一倍体验，这账怎么算都亏。

以前 1.5 倍就已经在交智商税了，现在 2 倍速度叠三倍单价，税还加码。

## # 这个周末：跑了十几个小时，交出来一坨

这个周末本来想干点正经事：重构一下雪涼云的 Web 前端、iOS 应用端，顺便把博客也收拾收拾。任务不小，所以直接丢给 Goal，挂着跑。

然后它就跑了十几个小时。

打开一看，我去，什么狗屎。丑就不说了——连用都用不了。

最典型的是审核页面。十多张图片全给我堆在最上面，图片描述又全部扔成一坨。我甚至分不清哪段描述对应哪张图，更别提单独删掉其中一张。删除入口在哪？没有。或者说有，但藏在这坨布局里跟没有一样。

一个审核页，核心不就是：看图、看描述、过或者不过、不行就删。这四件事它一件都没做明白。十几个小时的 Goal，换来一个自己都看不懂的后台。气都气笑了。

再翻翻它到底干了些啥，更离谱。审计报告里塞了一大堆测试日志，UI 录制直接给我整了 60 多 GB。磁盘都快被它自己的作业证明写满了，真正能用的页面还是没有。

最搞不懂的是它非得纠结那个大字版。系统字体拉到最大的布局它抠了又抠，跟这是什么核心功能似的。谁他妈用这个手机还把字体开到最大？你十几个小时不去做审核页能不能看懂，去伺候一个几乎没人会开的无障碍极端档，这精力分配已经不是偏了，是跑飞了。

你要说它没干活，token 倒是烧得挺认真，磁盘也占得挺实在。你要说它干完了，交出来的东西还不如我周末自己改两小时。

## # 小结

这几天的体验就这几句：

1. **编码没有质变**，手感更便秘，还把 5.6 Sol 一起拉下水；
2. **审计是真逆天**，全权限还要文字授权，烧的还是我的 token；
3. **UI 和 Goal 完成度很差**，几小时任务里大部分时间在自我审查，回复还慢；
4. **价格最诚实**：Astra 大约三倍消耗，效果最多 1.1 倍，Fast 还从 1.5 倍直接拉到 2 倍；
5. **周末那次 Goal 是实锤**：十几个小时重构雪涼云前端、iOS 和博客，审核页图片堆顶上、描述糊成一团，连删一张图都找不到；审计报告和 UI 录制占了 60 多 GB，还在死磕几乎没人会开的大字版。

Claude 新模型好歹让人感觉到“啊，这代确实不一样”。ChatGPT 这边更像是发了个更贵、更慢、更爱审计的版本，然后指望用户自己脑补质变。跑十几个小时交出来不能用的页面，这已经不是手感问题了，是活没干完还好意思交差。

要不是 Claude 连着封了我两个号，我都想换 Claude Code 了。两个号都养了一年，一订阅就封。免费用的时候没事，钱一交立刻凉，这已经不像是账号问题。我感觉是设备被标记了——同一台机器、同一套环境，换号也没用。模型是真想用，号是真留不住。

## # 接下来打算

被这十几个小时教育完，后面不搞那种“重构一切”了。

雪涼云只做最功能性的微重构：结构不动，只微调交互。审核页能不能看懂、一张图能不能单独删、描述到底贴在哪张图下面，这类问题优先；大改版、重做信息架构这类事先放一边。博客也暂时不重构了，能用就先用着。

签到插件这边，下一步是把现在的 token 共享再往外扩一截：接到鸣潮插件。现在只打通了米游社，以及米家那几套插件的登录共享。鸣潮也想看一眼角色毕业了没有，但又不想把社区查询面板、养成计算器、全套角色图鉴全塞进签到插件里。签到插件继续只负责账号和凭证，查询还是给专门的游戏插件去做——只是登录不用再绑一遍。

说白了就是：雪涼云小修交互，博客先停手，签到插件把登录共享从米家扩到鸣潮。别的大工程，等自己动手，不打算再丢给 Goal 跑一晚上。
