## # 前言

昨天的博客结尾说"v0.2.1-beta.1 在准备"，今天凌晨六点多它就发了，下午又发了 v0.2.1-beta.2。加上官网上线，三天时间，从"能不能做出来"到"能稳定发出去"，再到"有门面了"。

今天没有昨天那种大功能，但有几件事挺值得记：一次"版本限定可逆临时补丁"的实践、Companion 非宠物阶段收口、还有 CI 发布链终于跑顺。

## # 上午：仓库开始像个正经开源项目

第一件事（07:11）是给仓库补社区基建：GitHub issue 模板——bug 反馈模板、功能请求模板。以前别人想报 bug，得自己琢磨怎么写；现在点 New issue 就有结构化模板，环境信息、复现步骤、诊断包该传哪儿，全给你框好了。README 也补充了可发现性的内容。

## # 上午：Companion 非宠物阶段收口

第二件事（07:31，25 个文件）是把 Desktop Companion 非宠物阶段的工作收口，几个细节：

- **Markdown 预览的安全相对链接**：现在可以点开，并在当前工作区继续打开对应文件；协议 URL、绝对路径、越界路径、symlink 依旧拒绝。
- **文件预览缓存**：新增 64 MiB 的 LRU 缓存，按 revision 校验；切换工作区时随 Inspector 一起释放，不会把旧工作区的文件内容留在内存里。
- **窗口最小宽度**收到 820px，并补齐 820/980/1180/1480 四档布局验证（overlay、docked、Review Focus、宽屏审核）。

文档状态也同步更新了：非宠物阶段完成，下一阶段是角色素材冻结后的宠物动画。宠物这块从第一天的路线图就挂着，现在明确"代码侧能做的都做完了，剩下的卡在素材"。

## # 下午：v0.2.1-beta.2 —— 一次"版本限定临时补丁"的实践

下午连发两个提交（13:43 + 14:14），修了三件事，15:13 发 v0.2.1-beta.2。

三个问题：

1. **更新入口错位**。之前更新入口挂在 Harness 品牌行里，官方 UI 一更新，DOM 结构变了，入口就错位甚至被挤出界面。现在改成侧栏右下角固定的图标按钮，不再依赖 Harness 的 DOM 结构，侧栏或窗口尺寸变化时自动重新定位。
2. **余额区域挤压**。没配置 API Key 的时候，账户余额的说明文字会把侧栏挤爆。改成纵向排布，图标和"设置"对齐。
3. **自定义模型没法声明图片能力**。这个最有意思。官方 adapter 其实已经支持每个模型的 `models[].input` 字段，但官方模型设置页没有对应的控件——你手工声明一个视觉模型，它会被保守地回退成"仅文本"。

第 3 个的解法值得单独说说：**给随包 Harness 打一个版本限定的可逆补丁**。

- 只改一个文件（`dsh-client-ui-settings-models/lib/client.js`），在模型行的展开区域加"自动继承 / 仅文本 / 文本与图片"三个选项；
- 带版本保护：补丁只对 `0.1.0-rc.7` 生效，升级 Harness 时构建会要求人工复核，绝不自动套用到别的版本；
- 可逆：`unpatchModelCapabilitiesEditor()` 能把官方 bundle 逐字还原，往返测试保证"打得上去、拆得下来"；
- 官方哪天提供了同样的控件，按 `docs/12-temporary-harness-patches.md` 里的步骤把补丁删干净就行。用户已保存的 `models[].input` 是官方 schema 的合法字段，撤掉 UI 补丁不会破坏配置。

这个思路我觉得挺对的：**上游缺的控件，用临时补丁补，但动手之前先把"上游修好了怎么撤"想清楚**。测试也分了两层：单元测试用隔离的 fixture，不碰真实 bundle；集成测试才打真包验证。

## # 官网：deepseek.yukiryou.icu

然后就是今天的第三件事——官网。

用 Astro 做的静态站（跟博客一个框架），部署在腾讯 EdgeOne 上。内容结构：

- **Hero**：真实应用截图（浅色/深色两套），最新版本和下载按钮；
- **功能特性**：8 张卡片，打开即用、原生体验、账户余额、工作区审阅、文件预览、逐轮变更、生命周期、可信更新；
- **为什么选择**：和"官方 Web UI / 浏览器快捷方式"的对比表——运行环境准备、桌面能力、进程管理、更新方式、离线可复现；
- **工作原理**：从 `.app` 到内置运行时到随机回环端口的六步图；
- **安装三步、路线图、安全与隐私、FAQ**，中英双语（中文默认挂 `/`，英文挂 `/en/`）。

四个提交上线的：初始版 → 用真实应用截图替换模拟窗口 → 换深色主题截图 → 加 Google 站点验证 meta。

有个对比挺感慨的：三天前博客里写的是"正式对外发还差三样东西"，今天官网都挂出来了，还配了对比表教用户"为什么别用浏览器快捷方式"。

## # 发布链彻底跑顺

还有一条线是这两天一直在磨的：发布。今天的状态文档明确写了：

- CI Secrets 和发布链已经实际验证过；
- v0.2.1-beta.1 走完了完整链路：签名 → 异机安装 → 30 分钟真实打包应用 soak → 公证 → staple → 最终 DMG/ZIP 异机复验，然后公开发布；
- 以后新版本走 CI 出包，不再在本地直接公开产物。

也就是说，从 v0.1.0 到 v0.2.1-beta.2，三天五个公开 Beta，发布这件事从"本机脚本"彻底变成了"可信流水线"。
