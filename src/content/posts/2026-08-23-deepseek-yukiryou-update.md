## # 前言

昨天到今晚，连着发了 v0.2.3-beta.1、beta.2，今天 beta.3。这版是把 v0.2.2 那几条"转向"真正落地的一次里程碑：**Windows 11 x64 出来了、插件市场出来了、区域更新和国内镜像也有了**。

从这一版开始，我不会再逐个小版本往博客上写了——小修小补不值得记录，里程碑或方向性变化再单独写。所以这篇就把 v0.2.3 整个系列好好记一下。

## # 跨平台：Windows 11 x64 落地

这是最重的一条。v0.2.3 之前只有 Apple Silicon macOS，Windows 在路线图里还是"规划中"，这版直接变成 Beta，跟 macOS 进**同一个 GitHub Release**，出两份平台产物。

- **beta.1** 起步：Windows Runtime、ConPTY、Windows 图标、Squirrel 安装包 + 便携 ZIP；真实 Windows runner 验证了启动/重启、会话恢复、首次安装、同版本修复安装、卸载、快捷方式和注册项清理、用户数据保留。
- **beta.1 的坑**：Windows 普通用户首次启动起不来——之前依赖管理员权限或 Developer Mode。**beta.2** 修成目录 junction 装配，并给首次组装 Runtime 加了 60 秒超时，顺带把"关于"和更新界面里的 macOS/DMG 文案全改对了。
- **beta.3** 现在：Setup 换成向导式 NSIS 安装器，可选安装目录；便携 ZIP 解压即用；自绘标题栏和原生窗口按钮跟随主题，菜单语言跟着 Harness 设置走。

诚实说一句：Windows 产物目前**没有做 Authenticode 签名**，系统可能会弹 SmartScreen 警告。请只从这个 Release 下载，核对 `SHA256SUMS-Windows.txt`。Windows on Arm 和正式签名留到后面。

## # 插件市场：第一版可受管的社区插件目录

v0.2.3 另一个重头是插件市场。功能只是表象，真正花力气的是它的安全模型。

- **发现**：完整目录索引、搜索、分类、分页、来源管理；能看到目录来源、本机状态和安装前安全预检。
- **受管生命周期**：安装、更新、同版本重装、启用、停用、回滚到上一验证版本、安全卸载。所有写操作不绕过安全：一次性预览、系统原生确认、**冻结依赖图**、真实包体验证、离线 generation、重启后的双健康检查；任何一步失败都自动回滚旧版本并阻断已知的坏 generation。
- **来源**：新增"YukiRyou · 实机验证"来源，由独立公开目录动态维护，只收录我亲自装过并冒烟测试过的精确版本。但要说清楚：**这不是代码审计，也不是绝对安全保证**，安装前的完整预检和原生确认照走不误。
- 顺手修了个实际 bug：插件索引（dshfind）增长到 10,604 条、107 页后超过了旧容量上限读不出来；现在完整扫描（来源 10,604 条、规范化 10,603 条）配 24 小时持久缓存。

安全边界没松：目录只提供**发现能力**，不表示官方认可；安装前核验 npm 精确身份、仓库回链、废弃状态、安装生命周期脚本、SHA-512、官方 tarball、平台约束、DSH bundle、Node、完整依赖图、Peer 兼容性和实际包体。插件装好后仍和 Harness 共享本机用户权限——**请只安装你信任的代码**。

## # 区域更新 + 国内镜像

之前更新只有一条 GitHub 通道，国内下载体验很一般。这版加入了区域化：

- macOS 和 Windows 安装版统一支持后台下载 + 用户确认后的重启安装。
- **中国大陆优先走受 ESA 保护的 OSS 国内源**，其他地区走 GitHub；国内检查或下载失败会自动回退 GitHub。
- 同步有门禁：GitHub Release 公开且**全部门禁通过**，才允许同步 OSS；版本化对象回读校验成功，才会更新自动更新元数据、官网 `downloads/latest.json` 和国内插件目录。

## # Harness rc.2 与账户概览

- 内置 Harness 升级到 `0.1.1-rc.2`：Vision Exp 模型、Files API 图片复用、确定性的图片缩放/格式转换、上游沙箱安全修复。
- rc.2 存储格式改动，首次打开前会给非空 Runtime Home 建独立回退副本（不覆盖已有的 rc.8 备份）。
- **账户概览**：默认显示官方账户余额，鼠标悬浮在同一位置切换成"本机今日估算消耗"，点击同时刷新两项。估算按官方逐请求 usage + 北京时间工作日峰谷费率算，**不冒充官方账单**——这个边界我一直很在意。

## # UI 收敛

- 移除重复的"外观"页面，浅色/深色/跟随系统统一走 Harness 官方"通用设置 → 外观"；完整 UI 风格作为声明式插件扩展。
- 开发版和正式版用户数据隔离，避免调试状态污染已安装应用。

## # 小结

v0.2.3 的意义在于，DeepSeek YukiRyou 从"一个 Mac 应用"变成了"跨平台桌面工作台"：

1. **双平台**：macOS Apple Silicon + Windows 11 x64（Beta，同 Release 出包），Windows 暂未签名；
2. **插件市场**：可受管的发现 + 生命周期 + 严格信任模型，从"装插件"升级成"可控地装插件"；
3. **区域更新**：国内 OSS 源 + GitHub 回退，双平台都能后台下载、确认后重启安装；
4. **Harness rc.2** + 账户概览（余额 / 估算消耗）。

状态也如实：插件生态完善是"持续开发"，Windows 的 Authenticode 和 Windows on Arm 留后续，手机远程控制还是"规划中"。宠物继续不在当前产品线。
