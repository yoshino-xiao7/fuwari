## # 最近更新了什么

### 博客全站 Liquid Glass 效果

这大概是最近最大的视觉变化了。

之前一直觉得博客的卡片样式太"素"了，就是普通的白色/深色背景卡片，放在那里中规中矩但毫无新意。刚好最近看到 Apple 在推 **Liquid Glass** 的设计语言，那种透明毛玻璃的质感实在太好看了，于是就动手改了。

具体做了什么呢：

- **全局 card-base 改造**：所有文章卡片、Profile 卡片、导航栏、归档面板统一换成半透明毛玻璃背景 + `backdrop-filter: blur(16px) saturate(180%)`
- **侧边栏组件**：音乐搜索、图片抽卡等小组件全部替换成了自制的 `LiquidGlassLayout` 组件，带有鼠标响应式渐变边框和弹性缩放动画
- **全局音乐播放器**：迷你播放器、展开播放器、侧边收缩按钮三种状态都做了毛玻璃适配
- **字体可读性**：加了 `text-shadow` 规则和强制文字颜色，确保在半透明背景上文字还是看得清的

效果自己还是挺满意的，整个站点现在看起来通透了很多，有一种"悬浮在背景上"的感觉。

> 当然代价是写 CSS 写到头秃。`backdrop-filter` 的兼容性、暗色模式的颜色调整、文字在各种背景色下的可读性……每一个都够折腾半天的。

### Endfield Cloud 持续迭代

年前的终末地助手一直在小幅更新：

- **抽卡记录分析**：新增了抽卡记录同步和统计分析功能，可以看到 UP 命中率、平均抽数、总花费等数据。当时写这个功能的时候连 API 数据格式都要自己摸索，不过好在最终效果还不错
- **并发爬取修复**：之前发现多个爬取任务会同时运行导致 API 过载，加了任务锁机制确保同一时间只有一个爬取任务在跑
- **Umami 统计修复**：博客的浏览量统计一直报"统计不可用"，排查了半天发现是 Umami Cloud API 偷偷改了 `compare` 参数的格式，从 `false` 变成了 `prev`……

> **永远不要相信第三方 API 的向后兼容性。** 这是我今年学到的第一个教训。

### Yunzai Bot 终末地插件

年前写的 QQ 机器人插件也在持续维护中，主要是跟着游戏版本更新做一些适配。群友用得还挺开心的，偶尔能收到"签到提醒好评"的反馈，也算是值了。

## # 接下来的计划

说完"做了什么"，该聊聊"打算做什么"了。下面是我脑子里排队等着的项目/想法，按优先级排序：

### 1. Setu Cloud v3 大重构

这个是优先级最高的。

v2 系列已经运行了快四个月了，功能上虽然够用，但代码质量嘛……当时赶工写的，自己回头看都觉得有点头疼。v3 打算做一次比较彻底的重构：

- **后端**：考虑从 Java 迁移到更轻量的方案（Cloudflare Workers 或者 Hono），降低服务器成本
- **前端**：UI 全面升级，可能会引入类似 Liquid Glass 的设计风格
- **图库系统**：增加标签搜索、图片分类、质量评分等功能
- **开放 API v3**：重新设计 API 接口，更规范、更灵活

### 2. 短链服务优化

之前搭的 ki1.mom 短链服务基本功能已经齐了，但总觉得还能更好：

- 加一个简单的统计面板，能看到各短链的访问趋势图
- 支持自定义短码（比如 ki1.mom/blog 直接跳到博客）
- 二维码生成功能

### 3. 博客功能完善

这个博客本身也有一些想做的事情：

- **搜索优化**：全文搜索体验还可以改进
- **国际化**：虽然大概率不会写英文文章，但万一呢？
- **性能优化**：背景图 + 毛玻璃效果在老设备上可能会比较吃力，需要做降级方案

### 4. 新项目？也许吧

脑子里还有几个不太成熟的想法：

- 一个面向开发者的在线工具集合站（JSON 格式化、正则测试、颜色转换之类的）
- 给终末地做一个更完善的 Wiki 或数据库站点
- ~~或者干脆写个自己的音乐播放器后端，不再依赖网易云 API~~

不过这些都是"想法"阶段，能不能动手还要看时间和精力。

> 每次写计划的时候都豪情万丈，回头一看去年的计划，完成率大概 30%。希望今年能提高到 35%。
