## # Apple Store × 异环：周边到手了

今天去 Apple Store 逛了一圈，顺手薅到了 **异环（Hotta Studio）** 的联动周边——**两枚角色徽章**！

异环是 Hotta Studio（就是做幻塔的那家）正在开发的新作，目前还没正式上线，但已经开始跟 Apple 搞线下联动了。不得不说宣发这块确实可以，游戏还在预热阶段就先把周边铺出来了，这波属于**先用周边把你拿下，上线之后你不玩都不好意思**。

拿到手的是两枚圆形亚克力徽章，包装是黑色底卡配上「异环」的 logo，简洁利落。

徽章的印刷质量不错，闪粉底纹在光线下会微微反光，不是那种廉价感的平涂。边缘一圈英文字母环绕设计也挺有巧思的，整体观感比预期好。

> 虽然游戏还没上线，但周边已经先入坑了。这算不算一种「超前消费」？

说实话对异环这款游戏还是挺好奇的。Hotta Studio 在幻塔上积累了不少经验（和教训），异环能做成什么样确实让人期待。至少从美术风格来看，角色设计的水准是在线的。

> 先收着，等游戏上了看看质量再决定要不要入坑。不过按照我的历史记录，大概率到时候还是会忍不住下载的。

## # 终末地插件近况：一个 issue 引发的连锁更新

说完快乐的周边开箱，来聊一下终末地插件最近的开发进展。

插件发布之后用的人其实不算多，但前几天收到了**一个 issue**——有人反馈 `#终末地帝江号` 指令直接报错用不了。

一查才发现是 API 那边**悄悄改了角色 ID 的格式**，从纯数字 ID 变成了 `chr_xxxx_name` 这种前缀格式，老映射表直接废了，所有角色头像和名字都对不上号。花了一整个下午重写了 ID 映射系统，同时兼容新旧两种格式，房间排序和命名逻辑也顺手修了。

修完 bug 之后顺手看了一眼之前写的那些 UI……怎么说呢，越看越不满意。

### 自己动手重构 UI

说实话，我一直知道自己在 UI 设计这块是短板。v1.0 的渲染卡片基本就是"数据罗列+能看就行"的水平——功能是没问题，但视觉上真的很素，跟别的插件一比就显得特别「毛坯房」。

之前一直安慰自己"功能优先，UI 以后再说"，但既然都在改帝江号了，索性就趁这个机会把所有渲染模板**全部推翻重做**了一遍。

重新搭了一套统一的视觉语言：

- 深色背景 `#1a1d2e` + 卡片 `#242840`
- 网格布局、进度条、颜色判定系统
- 信息卡改成六段式：Header 标识栏、理智恢复进度条、4×2 统计网格、领地详情、活跃度进度条、干员展示网格

改完之后确实好看了不少——至少我自己觉得从「毛坯房」升级到了「简装房」的水平。

> 但终究不是专业做 UI 的，怎么调都感觉差点意思。如果有**擅长 UI 设计的朋友愿意来帮忙**，那真是太好了。一个人又写逻辑又调样式，实在是有点分身乏术。欢迎感兴趣的朋友来聊聊！

### 抽卡同步 524

另外还修了一个比较隐蔽的问题。部分用户首次同步抽卡记录时会碰到 **HTTP 524 超时**，排查之后发现是大数据量串行请求导致 API 网关超时。优化了请求策略和超时阈值之后基本解决了。

> 自己测试的时候数据量太少、网络太好，**永远测不出真实环境的问题。**

虽然用的人不多，但既然有人在用，那就得对得起这份信任。后续会继续慢慢迭代的。

> 当然速度可能取决于当天有没有在拉电线。
