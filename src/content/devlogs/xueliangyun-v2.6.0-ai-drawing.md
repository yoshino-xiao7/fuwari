## 更新概述

雪涼云 **2.6.0** 是一次围绕 **AI 绘图服务** 展开的版本更新。

这次更新把闲置本机上的 ComfyUI 出图能力接入到了雪涼云业务体系中：用户在云端控制台提交绘图任务，云端后端负责登录鉴权、积分扣除、任务排队、历史记录、OSS 存储、广场审核和删除流程；本机只作为 AI Worker 主动轮询任务，不需要把本机端口暴露到公网。

简单来说，雪涼云现在不只是图片 API 和图库服务，也开始尝试提供自己的 AI 绘图能力。

当前功能仍处于 **Beta 阶段**，生成质量、模型预设、LoRA 预设、提示词体验和广场内容生态都会继续优化。

## 用户端新增 AI 绘图

新增用户端入口：

```text
/dashboard/ai-draw
```

在 AI 绘图页面中，用户可以：

- 输入自然语言描述。
- 生成正向提示词和反向提示词。
- 直接编辑正向提示词和反向提示词。
- 只填写提示词直接生图，不强制使用自然语言描述。
- 选择 checkpoint。
- 选择 LoRA，或选择不使用 LoRA。
- 选择角色预设。
- 调整 LoRA 强度。
- 使用固定画幅预设。
- 查看当前生成任务状态。

当前画幅预设：

| 画幅 | 尺寸 |
| --- | --- |
| 竖屏 | `832x1216` |
| 横屏 | `1216x832` |
| 大头照 | `1024x1024` |

默认参数：

- `35 steps`
- `CFG 4.5`
- 每张图消耗 `50` 积分
- 管理员账号免费

## 我的 AI 历史

新增用户端历史页面：

```text
/dashboard/ai-history
```

用户可以在这里查看自己的 AI 生成记录。

支持能力：

- 查看自己生成过的图片。
- 按任务状态筛选。
- 查看原图。
- 复用上一次的 prompt 和生成参数。
- 将满意的图片提交到 AI 广场审核。
- 提交删除申请。
- 查看删除申请状态。

生成完成后的图片不会只停留在当前任务卡片里，后续可以在“我的历史”中继续查看。

## AI 广场

新增 AI 广场页面：

```text
/dashboard/ai-square
```

AI 广场用于展示用户提交并通过审核的公开 AI 图片。

支持：

- 全年龄分类。
- R18 分类。
- 全部分类切换。
- 仅展示审核通过并公开的图片。

未提交审核、审核中、审核拒绝、已下架或已删除的图片不会进入 AI 广场。

---

## AI 广场审核与删除流程

AI 绘图使用独立审核流程，不复用原来的图库投稿审核表。

用户生成图片后，可以选择提交到 AI 广场审核：

- 可提交为 `全年龄`。
- 可提交为 `R18`。
- 管理员审核通过后进入对应广场分类。
- 管理员拒绝后不会公开。

删除流程也独立处理：

- 用户不能直接删除已生成图片。
- 用户可以提交删除申请。
- 管理员审核通过后，记录会从历史、管理员列表和 AI 广场中隐藏。
- 删除时会尝试清理 OSS 中的私有图和公开图。

这样可以避免误删，也能让公开内容维持基本审核秩序。

## API Key 生图能力

本次新增 API Key AI 绘图接口：

```text
/ai-api/**
```

规则：

- 普通 API Key 生图会扣 Key 所属用户 `50` 积分。
- 管理员用户创建的 API Key 生图不扣积分。
- API Key 生图和登录用户生图进入同一套任务队列。

这为后续把 AI 绘图能力开放给脚本、Bot 或第三方调用预留了接口基础。

## 本机 AI Worker

本次新增本机 AI Worker 项目：

```text
setu_ai_wife
```

本机负责运行：

- ComfyUI。
- FastAPI 本机服务。
- cloud worker。

Worker 不需要公网暴露端口，而是主动轮询云端任务。

工作方式：

1. 云端用户提交 AI 绘图任务。
2. 云端进入任务队列。
3. 本机 Worker 主动领取任务。
4. Worker 调用本机 ComfyUI 生成图片。
5. 生成完成后回传云端。
6. 云端写入 OSS。
7. 用户在历史和任务卡片中查看结果。

一键启动脚本：

```powershell
cd C:\Users\rdpuser\Documents\setu_cd\setu_ai_wife
powershell -ExecutionPolicy Bypass -File scripts\start_cloud_all.ps1
```

该脚本会依次启动：

1. ComfyUI
2. 本机 FastAPI 服务
3. cloud worker

## OSS 存储与访问规则

AI 生图不会保存到云服务器本地磁盘，统一写入 OSS。

路径规划：

```text
ai/private/{userId}/{jobId}.png
ai/public/general/{jobId}.png
ai/public/r18/{jobId}.png
```

访问规则：

- 用户只能查看自己的历史图片。
- 管理员可以查看全部 AI 生成记录。
- 未审核图片只保留在私有路径。
- 审核通过后才进入 AI 广场公开路径。
- 删除通过后会隐藏记录，并尝试清理 OSS object。

## 管理员后台

新增管理员页面：

```text
/admin/ai-generations
/admin/ai-reviews
/admin/ai-delete-requests
```

管理员可以：

- 查看全部用户 AI 生图记录。
- 按用户 ID、任务状态和审核状态筛选。
- 查看图片、prompt、尺寸和失败原因。
- 审核 AI 广场提交。
- 下架已公开图片。
- 审核用户删除申请。
- 直接删除 AI 生图。

## 积分与退款规则

积分规则：

- 普通登录用户创建任务时扣除 `50` 积分。
- 普通 API Key 创建任务时扣 Key 所属用户 `50` 积分。
- 管理员和管理员名下 API Key 免费。
- Worker 或系统失败导致最终无法出图时，会自动退还已扣积分。

不退积分的情况：

- 用户不满意生成结果。
- 用户未提交广场审核。
- 广场审核被拒绝。

## 注意事项

- AI 绘图目前仍是 Beta 功能。
- 云服务器不需要访问本机 Worker。
- 不需要公网暴露本机 `7861` 或 `8188` 端口。
- AI 生图为独立业务域，不复用图库投稿审核表。
- 如果 OSS 没有 `DeleteObject` 权限，数据库删除仍会完成，但 OSS 文件可能残留。
- 模型、LoRA 和角色预设来自当前在线的本机 Worker，上线内容会随 Worker 配置变化。
