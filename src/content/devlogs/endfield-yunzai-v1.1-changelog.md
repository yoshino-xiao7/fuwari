## 更新概述

**v1.1** 是 Endfield Suzuki Plugin 的首个功能迭代版本，聚焦于 **稳定性修复** 与 **画面输出质感全面升级**。此版本对所有图片渲染模板进行了统一重设计，并修复了多个影响核心功能的 bug。

---

## 🐛 Bug 修复

### 帝江号指令崩溃修复

- **问题描述**：`#终末地帝江号` 指令在部分玩家数据场景下触发报错无法正常输出，原因是 API 返回的角色 ID 格式从纯 ID 迁移为 `chr_xxxx_name` 前缀格式，导致角色头像和名称映射失败
- **修复方案**：实现了完整的角色 ID 映射系统，兼容新旧两种 ID 格式；同时修复了房间类型排序与命名逻辑，确保基建房间按正确顺序渲染

### 抽卡同步 524 超时修复

- **问题描述**：`#终末地抽卡统计` 首次同步抽卡记录时，大量数据的串行请求可能导致 API 网关返回 HTTP 524（Timeout）错误
- **修复方案**：优化了同步请求逻辑，改善 API 请求处理策略与超时阈值，增加更健壮的重试/异步机制，确保大数据量同步场景下的稳定性

## ✨ `#终末地信息` 指令增强

玩家信息卡从简单的数据罗列升级为信息密度更高、布局更直观的六段式卡片设计：

### 新增数据展示

| 区域 | 展示内容 |
|------|----------|
| **Header** | `▼/// ARKNIGHTS: ENDFIELD` 标识 + 头像 + 昵称 + 苏醒日（绿色 badge）+ UID |
| **理智卡** | 当前/最大理智 + 可视化进度条 + 自动恢复时间计算（7分12秒/点） |
| **统计网格** | 4×2 网格：探索等阶、探索等级、干员数、武器数、总控中枢等级、醚质、储藏箱、光荣之路 |
| **领地卡片** | 各领地区域（四号谷地、武陵等）定居点列表与等级 |
| **活跃度卡** | 活跃度进度条 + 通行证进度条 |
| **干员网格** | 前 8 位干员（按稀有度 + 等级排序），含头像、E等级、属性 badge |

### 新增数据计算

- ⚡ **理智恢复时间** — `(maxStamina - curStamina) × 432秒`，格式化为 `Xh Ymin`
- 📅 **苏醒日** — 从 `createTime` 自动提取
- 🏗️ **总控中枢等级** — 从帝江号房间中提取 `type=0` 的等级
- 📊 **收集汇总** — 醚质 / 储藏箱 / 光荣之路数据
- 👥 **干员排序** — 稀有度优先，等级次优先

## 📄 抽卡统计页重设计

抽卡统计页同步升级为三列网格布局，支持多维度数据展示：

- **汇总卡片行** — 限定池 / 武器池 / 常驻池 / 新手池独立统计
- **三列详情区** — 限定池（左） / 武器池（中） / 新手+常驻（右）
- **子池卡片** — 带颜色条 Banner + UP 角色名 + 6★记录 + 保底进度条
- **颜色判定** — 50 抽内🟢 / 50~70 抽🟡 / 70 抽以上🔴
