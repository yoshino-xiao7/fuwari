## 项目简介

**雪涼云 Console** 是 [雪涼云 API](https://cloud.yukiryou.icu/) 的前端控制台，基于 **Aurora Glassmorphism（极光毛玻璃）** 设计风格打造，所有页面均适配桌面端与移动端。

当前版本：**v2.3.8**

## 核心功能模块

### 🏠 公开页面

- **SEO Landing Page** — 全屏 Hero 首页，OpenGraph / Twitter Card / Schema.org 结构化数据、自动 Sitemap
- **公开收藏夹** — 未登录用户可通过分享链接浏览
- **用户主页 & 系统状态页** — 公开访问，实时展示 API 运行状态
- **毛玻璃风格 404 页面**

### 🔐 认证系统

- 注册 / 登录 — 阿里云验证码（ESA）防护
- 找回密码 — 邮件验证 + Token 机制
- JWT Token — HttpOnly Cookie 存储，自动刷新与 401 拦截
- 请求签名 — CryptoJS 前端签名

### 👤 用户端 Dashboard

- **仪表盘** — 配额使用率、调用统计、最近调用日志（含分页）
- **API Key 管理** — 创建、重命名、禁用、删除、调用次数与剩余配额可视化
- **积分系统** — 积分余额、积分调用图片、流水明细
- **收藏夹** — 多收藏夹、公开/私有、封面设置、QR 分享
- **收藏夹广场** — 点赞、收藏、热度/最新/点赞排序、搜索
- **图片删除申请** — 提交请求并追踪审核状态
- **个人中心 / 开发文档 / 关于本站 / 隐私政策**

### 🎵 音乐播放器

- **网易云音乐集成** — 搜索、热门推荐、推荐歌单/新歌/每日推荐
- **多音质** — 标准 / 高品质 / 无损 / Hi-Res
- **歌词同步** — 逐行高亮 + 翻译歌词
- **MV 播放** — 多分辨率内嵌播放
- **全局迷你播放器** — 跨页面不中断
- **自定义歌单** — 创建/编辑/删除，顺序/随机/循环/单曲模式
- **播放历史** — 自动记录，分页查看

### 🛡️ 管理员后台

- 全站调用统计与系统状态
- 用户管理 — 多条件搜索、用户详情抽屉、封禁/解封/删除
- IP 黑名单 — 永久/临时封禁、批量操作
- 图片库管理 & 删除申请审核
- Pixiv 爬虫管理 — 按作品/作者/标签批量抓取、任务队列
- 网易云 Token 管理
- 深紫色独立管理员主题

## 设计与交互

- 🎨 **毛玻璃风格** — 高斯模糊玻璃质感卡片与弹窗
- 🌸 **樱粉色主题** — 统一 `#f586a9` 品牌色系
- 📱 **响应式布局** — 全面适配移动端，侧边栏可折叠
- ✨ **微动画** — 按钮悬浮、卡片入场、进度条渐变
