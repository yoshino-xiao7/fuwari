# 隐私政策

最后更新日期：2026年3月

## 概述

欢迎访问我们的博客网站 **[blog.yukiryou.top](https://blog.yukiryou.top)**，我们非常重视您的隐私和个人信息保护。本隐私政策说明了我们如何收集、使用和保护您在访问网站过程中提供的信息。请在使用本网站前，详细阅读本隐私政策。

## 网站性质

本网站是一个静态网站，采用 **Fuwari** 框架构建，网站内容是预先生成并托管的。我们不会主动收集您的个人信息，且不会在服务器端存储您的数据。以下是本网站的一些基本性质：
- 我们不存储您的个人信息。
- 网站内容是静态的，不会在每次访问时动态处理您的数据。
- 不会主动向您收集任何信息。

## 第三方服务

尽管本网站是静态的，我们仍使用了以下第三方服务，这些服务可能会收集和处理您的信息：

### 1. CDN 和托管服务

#### Vercel
- 可能收集的信息：您的 IP 地址、访问日志、性能数据。
- 用途：提供网站重定向服务，确保无论您通过哪个域名访问网站，最终都会重定向到 `blog.yukiryou.top`。

### 2. 分析和统计服务

#### Google Analytics（谷歌分析）
- 可能收集的信息：匿名化的用户数据、页面浏览量、会话时长、地理位置等。
- 用途：进行网站性能分析和用户行为分析。
- 使用 Cookie：是
- 隐私政策：[Google 隐私政策](https://policies.google.com/privacy)

#### 百度统计
- 可能收集的信息：页面浏览量、访问来源、访客设备信息等。
- 用途：网站流量统计与分析。
- 使用 Cookie：是
- 隐私政策：[百度统计隐私政策](https://tongji.baidu.com/web/help/article?id=330&type=0)

#### Microsoft Clarity
- 可能收集的信息：用户交互行为（点击、滚动）、页面热力图、会话回放。
- 用途：用户体验分析与优化。
- 使用 Cookie：是
- 隐私政策：[Microsoft 隐私声明](https://privacy.microsoft.com/zh-cn/privacystatement)

#### Cloudflare Web Analytics
- 可能收集的信息：匿名化的页面浏览量、访问来源、设备类型等。
- 用途：网站性能与流量分析。
- 特点：不使用 Cookie，注重隐私保护，所有数据均经过匿名化处理。
- 隐私政策：[Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)

### 3. 灵动岛时钟服务

#### 北京时间显示
- 网站顶部的"灵动岛"组件中，实时显示的北京时间(CST/UTC+8)由**您的浏览器本地 JavaScript Date API** 配合 `Asia/Shanghai` 时区自动计算生成，**不依赖任何外部时间服务器**（如 time.is 等）。
- 这意味着：该功能不会向第三方服务发起网络请求，也不会传输您的任何信息。

### 4. 音乐播放服务

#### 自建音乐 API（api.yukiryou.icu）
- 网站内置的音乐搜索与播放功能通过我方自建的后端 API 服务 `api.yukiryou.icu` 提供支持。
- 可能收集的信息：搜索关键词、请求的歌曲 ID、歌词获取请求。
- 用途：提供音乐搜索、音频流播放、歌词同步等功能。
- 数据来源：音乐元数据及音频流来源于第三方在线音乐平台，我们仅做中转代理。
- 说明：该服务不会记录或存储您的个人身份信息，搜索和播放行为不与任何用户身份关联。

### 5. 插画展示服务

#### 自建 Setu API（api.yukiryou.icu）
- 侧边栏的随机插画展示功能通过我方自建的 API 服务提供。
- 可能收集的信息：请求时间、请求参数。
- 数据来源：插画来源于 **Pixiv** 等第三方平台，我方数据库仅存储经过筛选的公开作品元数据和缓存图片。
- 说明：该服务不会主动收集您的个人信息。

## Cookie 和本地存储

我们的网站可能使用以下技术：
- **Cookie**：用于优化网站功能以及为您提供更好的用户体验。
- **本地存储**：用于保存您的偏好设置（如主题选择）。
- **会话存储**：用于临时存储页面状态，提升网站响应速度。

您可以通过浏览器设置禁用 Cookie，但请注意，这可能影响某些功能的使用。

## 如何保护您的隐私

为了更好地保护您的隐私，您可以采取以下措施：
- 使用隐私浏览模式访问网站。
- 禁用第三方 Cookie。
- 使用广告拦截工具保护隐私。
- 使用 VPN 服务隐藏您的真实 IP 地址。
- 定期清理浏览器缓存和 Cookie。

## 数据安全

我们采取以下措施来保护您的隐私：
